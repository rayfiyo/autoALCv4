# クレデンシャルの扱い

- 情報
  - ID
    - `s` + 非負整数 5 桁
      - 例: `s54321`
    - 数字 5 桁のみ指定されている場合は、プログラム側で `s` を付与する
    - `s` 始まりのため、数字ではなく文字列
  - Password
    - 記号を含む文字列
- 入力: 環境変数で指定が無ければ env ファイルを用いる
  - env ファイルのパス指定はフラグで行う
    - 例: `.env.example` ファイルを参照

# エラーの文言

- 日本語で行う

# フラグ（実行時オプション）

- `dot-env`: env ファイルのパスを指定する
  - デフォルト: `.env` （実行時直下の `.env`）
- `headless`: ヘッドレスモードを切り替える
  - デフォルト: true
  - デバック時などに false を指定
- `waiting-time`, `wt`: 各処理の待ち時間 [ミリ秒] を調整する
  - デフォルト: 1200
- `user-data-dir`: Chrome のユーザーデータディレクトリ
  - デフォルト: 空文字列
    - 空文字列の場合、`$HOME/.cache/chrome-user-data` になる
